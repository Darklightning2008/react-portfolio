🚀 Personal Portfolio Website

A modern, responsive personal portfolio website built with React and Vite to showcase my projects, skills, and journey as an engineering student interested in software development and technology.

🔗 Live Portfolio: https://react-portfolio-peach-eta.vercel.app/

⸻

📌 About the Project

This portfolio was developed as the capstone project of my one-month Full-Stack Development course.

The goal was to build a real-world web application while understanding the development process — from designing the interface and implementing reusable components to testing and deploying the application.

As an Aeronautical Engineering student interested in software and technology, I use this portfolio to showcase my technical projects and explore the intersection of engineering and computer science.

✨ Features

* Responsive Design – Optimized for desktop, tablet, and mobile devices.
* Modern UI – Clean interface with a consistent visual design.
* Reusable Components – Modular React components for maintainable code.
* Page Navigation – Smooth navigation using React Router.
* Animations – Interactive transitions and animations using Framer Motion.
* Contact Form – Integrated with Formspree for handling messages.
* Project Showcase – Dedicated section to highlight technical projects.
* Live Deployment – Hosted using Vercel.

⚙️ Getting Started

Follow these steps to run the project locally.

Prerequisites

* Node.js
* npm
* Git

1. Clone the repository

git clone <YOUR_GITHUB_REPOSITORY_URL>

2. Navigate to the project directory

cd portfolio

3. Install dependencies

npm install

4. Start the development server

npm run dev

Open the local URL displayed in your terminal to view the website.

5. Build for production

npm run build

🌐 Deployment

The portfolio is deployed using Vercel.

To deploy your own version:

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Configure the build command as npm run build.
4. Set the output directory to dist.
5. Deploy the application.
